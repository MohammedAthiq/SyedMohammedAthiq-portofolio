# 🌐 Athiq's Portfolio

A modern personal portfolio website built using **HTML, CSS, and JavaScript** to showcase my projects, skills, and achievements.  
The site is fully responsive and deployed on **Netlify** for smooth and fast performance.

---

## 🚀 Live Demo
👉 [Visit My Portfolio](https://syedmohammedathiq-portfolio.netlify.app/)

---

## 🧠 Features
- Responsive and clean UI  
- Interactive animations and transitions  
- Contact form powered by **EmailJS**  
- Smooth navigation and modern design  

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **EmailJS** (for contact form)
- **Netlify** (for deployment)

---

## ⚠️ Note
This project uses EmailJS for the contact form.  
Public keys are safe to expose as per EmailJS documentation, but private credentials are never shared.
